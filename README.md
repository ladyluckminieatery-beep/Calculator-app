# 🧮 Calculator App

A responsive calculator web application built with **HTML, CSS, and JavaScript**. This project was created to practice JavaScript logic, DOM manipulation, event handling, and responsive web design.

## ✨ Features

* Addition, subtraction, multiplication, and division
* Decimal calculations
* Clear/reset functionality
* Interactive calculator buttons
* Responsive design
* User-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and responsive design
* **JavaScript** — Calculator logic and user interactions

## 🚀 How to Use

1. Open the Calculator App.
2. Enter a number using the calculator buttons.
3. Choose an arithmetic operator.
4. Enter the second number.
5. Press the equals button to calculate the result.
6. Use the clear button to start a new calculation.

## 🎯 Purpose

This project demonstrates my ability to build an interactive web application using **HTML, CSS, and JavaScript** and to implement JavaScript logic and user interactions.
